Wave Machine: Instructor Notes

For the Virtual Wave Machine. This page isn’t linked from the student page because it contains answers to the problems in the handout.

Instructor mode

Open the simulation in instructor mode to get a Show predicted resonances checkbox under the energy plot. It draws a dashed line at each normal-mode frequency (for whichever end condition is set) and shades the forbidden band. The student page is the same without that checkbox.

Neither this page nor instructor mode is password-protected. Anyone who knows the address, or reads the page’s JavaScript, can find them. They are kept out of sight, not secret.

Notes on the handout problems

The handout is Oleg Tchernyshyov’s Elastic waves in one dimension (PDF).

  • Problem 1 (decaying waves below ω₀). The handout prints the decay constant as κ = s⁻¹√(ω₀² − ω₀). It should be κ = s⁻¹√(ω₀² − ω²), as the next paragraph of the handout uses.
  • Problem 2 (penetration length). With the default settings, ω starts at 0.2 rad/s. The continuum theory gives 1/κ = s/√(ω₀² − ω²) = 1/√(0.25 − 0.04) ≈ 2.2 rod spacings. The exact 12-rod model gives 2.20, which is an amplitude drop by a factor of about 0.63 from each rod to the next. Students can see this in the Angles view: set the sweep rate to 0 and let the motion settle.
  • Problem 3 (resonant frequencies). See the calculation and table below. Students using the handout’s continuum formula will get the middle column for free ends. For one end free and one fixed they will get slightly lower values than the exact column, e.g. about 0.517 and 0.636 rad/s for the first two modes.
  • Problem 4 (measuring them). Holding the frequency fixed (sweep rate 0) and stepping it by hand, the energy peaks land within about 0.002 rad/s of the exact values. With a sweep the peaks are shifted by the lag described below, so sweeping in both directions and averaging helps.

How the predicted resonances are calculated

In instructor mode, the dashed lines on the energy plot are the normal-mode frequencies of the 12 rods: the frequencies at which the whole machine can oscillate on its own, with every rod moving at the same frequency. Driving the machine at one of these frequencies builds up a large response, which is a resonance. Since the damping is weak, the resonances sit very close to the normal-mode frequencies.

1. Look for a standing wave

Number the rods n = 1 to 12 and try a standing wave of a single frequency ω:

θn(t) = A cos(q(n − ½)) cos ωt

Here q is the change in phase from one rod to the next. It plays the role of the wavenumber k in the handout, measured per rod.

2. Put it into the equation of motion

Without damping or drive, each rod obeys θ̈n = s²(θn+1 − 2θn + θn−1) − ω₀²θn. Using cos(x + q) + cos(x − q) = 2 cos x cos q, every rod gives the same condition:

ω² = ω₀² + 4s² sin²(q/2)

This is the dispersion relation of the wave machine. For long waves (small q), 4 sin²(q/2) ≈ q², which gives the handout’s ω² = ω₀² + s²k². It also shows why low frequencies are forbidden: the smallest possible ω is ω₀ = 0.5 rad/s, when q = 0. (There is also a highest frequency, √(ω₀² + 4s²) ≈ 2.06 rad/s, when neighboring rods swing opposite ways. That limit comes from the rods being discrete.)

3. Make it fit the ends

The boundary conditions decide which values of q are allowed.

  • Free end. Nothing twists the end rod from outside, as if an imaginary extra rod beyond the end always turned exactly with it. At the left end that means θ0 = θ1, which our cosine already satisfies. At the right end it means θ13 = θ12, which requires sin(12q) = 0, so q = πm/12 with m = 0, 1, …, 11.
  • Clamped end. Rod 12 cannot move: θ12 = 0. That requires cos(11.5q) = 0, so q = (2m + 1)π/23 with m = 0, 1, …, 10. Only 11 rods can move, so there are 11 modes.

4. The result

Putting the allowed q values into the dispersion relation gives the frequencies, with s = 1 s⁻¹ and ω₀ = 0.5 rad/s:

  • Both ends free: ωm = √(ω₀² + 4s² sin²(πm/24))
  • Right end clamped: ωm = √(ω₀² + 4s² sin²((2m + 1)π/46))

The continuum column uses the handout’s ω² = ω₀² + s²k² with k = πm/L and L = 12. It agrees with the exact values for the first few modes and drifts away for shorter waves, as footnote 1 of the handout warns.

Why the measured peaks can differ a little

  • Sweeping. A resonance takes time to build up, so while the frequency is sweeping, the peak shows up late: too high when sweeping up and too low when sweeping down. Sweep both ways, or slow the sweep down.
  • Damping lowers and broadens each peak and moves it very slightly. With the default damping the shift is far smaller than the sweep lag.
  • Where the drive is. The drive pushes only rod 1, so modes with little motion at rod 1 respond weakly and their peaks can be small.

The shaded region on the plot (instructor mode) is the forbidden band, ω < ω₀. Waves at these frequencies die away along the machine instead of travelling through it.
