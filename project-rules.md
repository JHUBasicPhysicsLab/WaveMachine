# Wave Machine Code Update

# Goal
I have an old piece of code, that was written in Java, to simulate a torsional wave apparatus.     I would like to create a modern version of this code to be hosted on our website.    

# Details
The torsional wave apparatus was invented by John Shive at Bell Labs https://www.compadre.org/osp/EJSS/5725/WaveMachine/WaveMachine.html.  It is a favorite demonstration for illustrating the properties of waves. 

I am not sure what the most useful language for coding this simulation is.   One option is a stand-alone python package (similar to what we did for the photoelectric effect).   Another option seems like a web-based simulation that could be accessed from anywhere (similar to a PhET simulation).    I think that I am leaning towards a web-based version. 

The current code is in the "wavemachine" folder in this directory.   

I would like to keep as much of the content as possible and be sure to appropriately credit the work that was originally done by Oleg Tchernyshyov.

I would like to add our updated code to its own project repository within the JHUBasicPhysicsLab repo.
